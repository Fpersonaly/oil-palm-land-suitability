# Oil Palm Land Suitability Prediction

A Machine Learning project comparing Decision Tree and Random Forest algorithms to predict land suitability for oil palm cultivation.

## Project Overview

This project was developed as part of an undergraduate thesis at the Institut Teknologi Sawit Indonesia (ITSI).

The study compares two classification algorithms to predict oil palm land suitability based on biophysical parameters.

## Objectives

- Classify land suitability into S1, S2, S3, and N.
- Implement Decision Tree and Random Forest algorithms.
- Compare model performance.
- Visualize model evaluation results through a web-based dashboard.

## Model Performance

| Algorithm | Test Accuracy |
|---|---:|
| Decision Tree | 88.30% |
| Random Forest | 97.99% |

## Dashboard Features

- Land suitability class distribution.
- Decision Tree evaluation.
- Random Forest evaluation.
- Model performance comparison.
- Feature importance visualization.

## Project Architecture

This project consists of two independent components:

1. Python-based machine learning models for data processing, training, and evaluation.
2. A web-based dashboard developed using HTML, CSS, and JavaScript to visualize previously generated model results.

The website does not directly execute the Python models.
